# 🤖 ModeratorBot — личный Telegram-модератор

Бот следит за твоими чатами **24/7 по твоим правилам** и мгновенно наказывает нарушителей:
мут, бан, кик, предупреждения. Работает в нескольких чатах одновременно.
Отвечает **только админу** — всех остальных полностью игнорирует.

## ✨ Возможности

- 🔒 Только ты (id `8587090554`, @desacratio) можешь управлять ботом
- 📜 Правила формата: `флуд - мут 1 час`
- 🌊 Детектор флуда (N сообщений за M секунд)
- 🔁 Детектор повторов/спама (одинаковое сообщение)
- 🔗 Детектор ссылок/рекламы (`http`, `t.me/`, `@упоминание`)
- 🤬 Детектор мата (встроенный словарь, легко дополнить)
- 💬 Правило на своё слово/фразу: `слово:айпи - кик`
- ⛔️ Наказания: 🔇 мут, ⛔️ бан, 👢 кик, ⚠️ варн (после N варнов — авто-мут)
- ⚙️ Настройки для каждого чата: удалять нарушение, уведомления, лимиты флуда/спама
- 🗂 Поддержка множества чатов
- 📊 Уведомления админу о каждом нарушении

## 🌍 Деплой на Render.com (бесплатно)

### Вариант A — Render Blueprint (проще всего)

1. Создай **публичный** репозиторий на GitHub и залей туда эту папку.
2. Зайди на [render.com](https://render.com) → **New → Blueprint**.
3. Укажи свой репозиторий. Render сам увидит `render.yaml`.
4. После создания открой сервис → **Environment**:
   - `BOT_TOKEN` — впиши токен от BotFather
   - `ADMIN_IDS` — оставь `8587090554` (или добавь ещё через запятую)
   - `ADMIN_USERNAMES` — оставь `desacratio`
5. Нажми **Manual Deploy → Deploy latest commit**.

### Вариант B — вручную (Web Service/Worker)

1. Создай **Background Worker**:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python bot.py`
   - **Plan:** Free
2. Добавь переменные окружения `BOT_TOKEN`, `ADMIN_IDS`, `ADMIN_USERNAMES`.

> ⚠️ Важно про бесплатный тариф: используй тип **Worker** (фоновый процесс).
> Поллинг Telegram — это постоянная активность, поэтому worker **не засыпает**
> и работает 24/7 в рамках бесплатных 750 часов в месяц.

### 💾 Постоянное хранение правил (рекомендуется)

На бесплатном тарифе Render диск эфемерный — при перезапуске правила могут
сброситься. Чтобы этого не было:

1. Заведи бесплатную базу на [neon.tech](https://neon.tech) (или supabase.com).
2. Скопируй строку подключения вида `postgres://...`.
3. Добавь переменную `DATABASE_URL` в Render.

Без этой переменной бот работает на SQLite-файле `moderator.db`.

## 🕹 Как пользоваться

### Подключение чата

1. Напиши боту → **/start**
2. Добавь бота в свой чат и **назначь администратором** (дать все права)
3. В меню: **➕ Добавить чат** → выбери чат
4. **➕ Добавить правило** → выбери чат → отправь правило:

```
флуд - мут 1 час
реклама - бан
мат - мут 30 минут
слово:айпи - кик
спам - мут 2 часа
```

### Формат правил

```
нарушение - наказание [длительность]
```

**Нарушения:** `флуд`, `реклама`/`ссылки`, `мат`, `спам`/`повтор`,
`слово:твой_текст`

**Наказания:** `мут`, `бан`, `кик`, `варн` (предупреждение)

**Длительность:** `30 минут`, `2 часа`, `1 день`, `1 неделя`, `навсегда`
(если не указана: мут = 1 час, бан = навсегда)

### Команды в чате (для админа)

| Команда | Действие |
|---|---|
| `/mute` (ответом) | замутить на 1 час (или `/mute 5 минут`) |
| `/ban` (ответом) | забанить |
| `/kick` (ответом) | выгнать |
| `/warn` (ответом) | предупреждение |
| `/unmute`, `/unban` (ответом) | снять наказание |
| `/rules` | список правил чата |
| `/addrule флуд - мут 1 час` | добавить правило в этот чат |
| `/delrule 2` | удалить правило по номеру |

## ⚖️ Ограничения

- Бот не может следить за чатами, где у него нет прав администратора.
- Флуд/спам-детектор работает «в памяти»: счётчики сбрасываются при рестарте.
- Словарь мата базовый — редактируй `src/profanity.py`.
